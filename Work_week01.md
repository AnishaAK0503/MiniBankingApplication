# Work Week 01 - Project Setup and PostgreSQL Basics

## Training Goal

Set up and run a Spring Boot backend independently and understand the basic development workflow.

## Completed Work

- Created the Spring Boot backend project using Maven.
- Established the standard controller, service, repository, DTO, entity, and exception package structure.
- Configured PostgreSQL connectivity for the banking database.
- Added basic health and information endpoints.
- Added the initial project README and local run instructions.
- Practised Git-based project organization and incremental commits.
- Verified that the backend can start and connect to PostgreSQL.
- Used HTTP clients/Postman-style requests to check API responses.

## Evidence in the Project

- `banking-backend/pom.xml`
- `banking-backend/src/main/resources/application.properties`
- Health and information controllers under `banking-backend/src/main/java/com/banfico/banking/controller/`
- `banking-backend/mvnw.cmd`

## Outcome

The backend could be started locally, connected to PostgreSQL, and tested through basic REST requests.
