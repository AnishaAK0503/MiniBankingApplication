# Work Week 03 - Frontend Integration and Maker-Checker Foundations

## Training Goal

Create an Angular frontend and connect it to the banking backend APIs.

## Completed Work

- Built Angular screens for the dashboard, customers, accounts, transactions, beneficiaries, profile, users, audit views, and request approvals.
- Connected Angular services to the Spring Boot REST APIs.
- Added forms with client-side validation and backend error display.
- Added loading, refresh, empty, success, and error states.
- Added pagination to the main listing pages.
- Added CSV export for customers, accounts, transactions, beneficiaries, requests, users, and audit listings.
- Added customer and account filtering workflows for beneficiaries and transaction views.
- Started the Maker-Checker account request flow with pending, submitted, approved, and rejected states.
- Added Checker approval screens and mandatory rejection reasons.
- Tested frontend/backend communication and fixed request, table, dropdown, and route issues.

## Outcome

The Angular frontend could create, list, filter, paginate, and export banking data while communicating with the backend. The first Maker-Checker request screens were also available for testing.
